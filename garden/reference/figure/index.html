2字段写法

```garden figure
svg: |      # 三选一，内联 SVG
image:      # 三选一，图片路径
mermaid: |  # 三选一，Mermaid 源码
alt:        # 可选，图片替代文本
parts:      # 可选，切换按钮
  - id:     # 对应 data-p
    label:  # 必填，按钮文字（或 name）
    text:   # 必填，说明
caption:    # 可选，图注
```

3字段

围栏写 ```garden figure（编辑器代码片段触发词 ;gfigure）。YAML 语法错误或顶层含未知键名时整块报 garden-yaml 错误。

字段是否必填默认值取值与限制说明
svg与 image、mermaid 三选一--- 分隔线下的 <svg> 正文或 ""多行 <svg> 字符串内联 SVG 源码；在需要随按钮高亮的图形元素上标注 data-p="<id>"（颜色建议使用 var(--card)、var(--ink)、var(--muted) 等主题变量以适配深色模式）
image与 svg、mermaid 三选一无图片路径字符串静态结构图路径
alt可选同 caption（再回退为 ""）字符串image 的替代文本
mermaid与 svg、image 三选一无多行字符串Mermaid 图源码
parts可选[]（初始选中项默认 parts[0].id 或 "all"）对象数组图上方的切换按钮与图下方的对应说明
parts[].id建议填写同 parts[].name 或 parts[].label字符串对应 SVG 元素上的 data-p 标识（写 "all" 或 "全部" 时高亮全部区域）
parts[].label必填（或写 name）"部分 N"（按序号生成）字符串切换按钮上显示的文字
parts[].text必填""字符串选中该按钮时在图下方显示的说明文字
caption可选无字符串图框底部的图注

4限制与报错

  • 除通用的 garden-yaml 外，本组件没有专属报错代码；表里写「不做校验」的建议值不会报错。
