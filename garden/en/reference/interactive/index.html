Component reference · interactive

Let readers drag sliders or switches to recalculate formulas and charts in real time.

← Component reference · Usage: interactive

1Examples

Code

```garden interactive #reading-time
caption: "Example: estimate reading time from word count, reading speed, and image count. Numbers are illustrative only."
---
<State words={6000} speed={400} images={8} />
<Let textMinutes={round(words / speed)} />
<Let imageMinutes={round(images * 12 / 60)} />
<Let parts={[{ part: "Prose", minutes: textMinutes }, { part: "Images", minutes: imageMinutes }]} />

<Slider bind="words" label="Word count" min={1000} max={20000} step={500} unit="words" />
<Slider bind="speed" label="Reading speed" min={200} max={800} step={50} unit="wpm" />
<Slider bind="images" label="Image count" min={0} max={30} step={1} unit="images" />

<Stat label="Example: estimated reading time" value={textMinutes + imageMinutes} unit="min" hint="Counting 12 seconds per image" />
<Chart data={parts} x={part} yLabel="min">
  <Bar y={minutes} label="Example" />
</Chart>
```

Preview

2Syntax

```garden interactive #<id>
caption:               # required, default reading
intent: |              # optional, original idea
expect:                # optional, assertions
---                    # tags go below
<State ... />          # required, state
<Let ... />            # optional, derived values
<Slider bind="..." />  # input control
<Stat ... />           # output
```

4Limits & errors

  • Header: ui-id (missing or malformed id), ui-caption (missing caption), ui-header (intent not a string or expect not a list), ui-expect (malformed or failing assertion), ui-stale (warning: the idea changed but was not recompiled).
  • Tags: ui-prop, ui-expr, ui-cycle, ui-eval, ui-data, ui-bind, ui-limit, ui-children, ui-component, ui-markdown, ui-syntax; see the table above for what triggers each.
  • Whole block: interactive-trivial (a single simple multiplication), steps-prose (steps that are only prose, with no state change).
  • Run npx garden ui check to get a fix prompt.
