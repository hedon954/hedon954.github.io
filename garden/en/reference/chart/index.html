Component reference · chart

Render proportional horizontal bars with a built-in expandable data table underneath.

← Component reference · Usage: chart

1Examples

Code

```garden chart
title: Max Width by Layout Zone
xLabel: Layout Zone
yLabel: Max Width
unit: px
data:
  - x: Prose Column
    y: 740
  - x: Wide Figure Zone
    y: 1040
  - x: Wide Table Zone
    y: 1340
caption: Click "View data table" below to expand the full numeric table.
```

Preview

2Syntax

```garden chart
type:       # optional, bar only
title:      # recommended, heading
data:       # either this or series
  - x:      # name
    y:      # value
    label:  # optional, value label
x:          # labels for series
series:     # either this or data
  - name:   # optional, name
    data:   # numbers
unit:       # optional, unit
xLabel:     # optional, 1st column
yLabel:     # optional, 2nd column
caption:    # optional, caption
```
