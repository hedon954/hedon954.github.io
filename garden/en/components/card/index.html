Reference Card (card)

Summarize a paper, repository, or module in a card with metadata and numbered takeaways.

SQLite Write-Ahead Logging

Documentation · sqlite.org

Appends changes sequentially to a write-ahead log while readers continue reading the original database pages, reducing read-write contention.

  1. Writes append to the end of the -wal file instead of overwriting database pages in place on commit.

  2. Readers record the current end-of-log mark to see a consistent snapshot without blocking concurrent writers.

  3. Background checkpoints copy log pages back into the main database file in batches once a threshold is reached.

  • When to use: Introducing a paper, open-source project, or subsystem where a link and 2 to 4 numbered points belong together, or listing several tools or references with a takeaway line.
  • When to skip: A sentence or two of prose or a [Title](url){card} link card is enough.

You can tell the AI:

```garden
Summarize the SQLite WAL documentation in a card with a link, a one-sentence summary, and three takeaways.
```

1Multiple Resource Row Cards (cards)

When you want to list several projects, tools, or references in one block and attach a takeaway line to each, use cards:

Open Library: one page per book

An open catalogue run by the Internet Archive, with editions and e-book loans. Oopenlibrary.org

Worth borrowing: link the book's page when you pick, so everyone reads the same edition.

Project Gutenberg: public-domain e-books

E-books that have entered the public domain, free to download. Ggutenberg.org+1

Worth borrowing: pick a public-domain book now and then, so people without a copy can join at once.

You can tell the AI:

```garden
List Open Library and Project Gutenberg as two cards, each with a source link and a takeaway line on what is worth borrowing.
```
