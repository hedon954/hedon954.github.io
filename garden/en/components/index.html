1Reference Card · card

SQLite Write-Ahead Logging

Documentation · sqlite.org

Appends changes sequentially to a write-ahead log while readers continue reading the original database pages, reducing read-write contention.

  1. Writes append to the end of the -wal file instead of overwriting database pages in place on commit.

  2. Readers record the current end-of-log mark to see a consistent snapshot without blocking concurrent writers.
