Recommended figures

Names, schematics, use cases, and recommended briefs for the built-in Typora and VS Code figure list.

The /garden list in Typora and in VS Code / Cursor comes from the same built-in list. There are currently 21 items: 20 common figures, and Other as the last item. Choosing one inserts a single garden compose brief, not a different author fence. That brief is for your material and goal, not a syntax lesson.

Use Other when no built-in figure fits, or when you need to combine text and graphics freely. Do not treat the list below as a closed allowlist.

For the entry and compile steps, see Compose and Checks & Shortcuts.

Join diagram Use this to show how two sides connect through a middle item.

Fan-out diagram Use this to show a first stop that then branches to several places at once.

Layer diagram Use this to show top-down layers that do not have to be walked in order.

Aspect diagram Use this to show several aspects of one thing, with no required order.

Two-row contrast Use this to contrast a background process with the process you want to emphasize, on two rows.

Illustrated list Use this to explain independent items one by one.

Flow diagram Use this to show the order in which something is done.

Step diagram Use this to explain something step by step, with room for detail inside a step.

Comparison diagram Use this to compare two or three options under the same conditions.

Timeline Use this to arrange events by date or time.

Message sequence Use this to show who sent what to whom, and when.

Tabs Use this when several groups of notes are independent and the reader should see one group at a time.

Chart Use this to turn numbers you already have into bars, lines, or shares.

Tunable chart Use this when the reader should change one or two inputs and watch the result.

Conversion diagram Use this when one input should produce several results at once.

Code walkthrough Use this to walk through code line by line: what runs, and what the variables are.

Stepper Use this when the reader should pause on a step and see how state changes.

Path callout Use this to mark how far you have walked on an existing flow or state diagram.

Checklist Use this when the reader should follow items one by one and come back to check progress.

Grid diagram Use this to mark which cells in a two-dimensional structure matter, and why.

Other Use this when no built-in figure fits, and you need to combine text and graphics freely.
