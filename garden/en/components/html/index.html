Embedded Web Snippet (html)

Run a self-contained HTML, CSS, and JavaScript demo inside a sandboxed iframe.

  • When to use: Running custom DOM scripts, Canvas animations, physical simulations, or self-contained HTML widgets.
  • When to skip: You only need sliders wired to a formula (use interactive) or a diagram with clickable regions (use figure).

You can tell the AI:

```garden
Embed a small widget where typing in an input box updates the character count in real time.
```
