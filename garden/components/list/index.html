Garden 使用说明/内置组件garden list

图标列表（list）

用线条图标配短句列出几条并列动作，或带小标题列出分步做法。

  • 什么时候用：几条并列的行为、信号或做法，每条配一个线条图标；或者带小标题与分段说明的做法列表。
  • 什么时候不用：只是一组带编号的先后顺序时用普通有序列表；按时间演进的节点用时间线。

可以这样对 AI 说：

```garden
把新成员报名前常做的四件事列成带图标的列表：搜书名、看书评、收藏页面、在群里问能不能只听不说。
```

1带小标题的分段步骤列表

```garden
把这三个小实验列成带图标和小标题的步骤：确认阅读量、让新成员开口、测试提前几天发提醒。
```
