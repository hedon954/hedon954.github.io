知识卡片（card）

介绍一篇论文、一个项目或一组值得参考的公开工具。

SQLite WAL 写入模式

文档说明 · sqlite.org

把修改先顺序追加到预写日志，读操作继续访问原数据库页，减少读写互斥等待。

  1. 写入只追加到 -wal 文件末尾，不需要在事务提交时原地覆盖数据页。

  2. 读事务记录当前末尾偏移量即可看到一致快照，不会阻塞并发写入。

  3. 后台 Checkpoint 按阈值将日志页分批写回主库文件。

  • 什么时候用：介绍一篇论文、一个仓库或一本书，需要标题、链接和几条说明；或者把几项参考资源放在一起，各附一句可借鉴的结论。
  • 什么时候不用：正文里一两句话已经说清，或者只需要链接卡片时，直接写正文段落。

可以这样对 AI 说：

```garden
整理一张卡片介绍 SQLite 的 WAL 文档，带链接和三条核心要点。
```

1多张资源行卡（cards）

需要连续列出几个项目、公开工具或参考资料，并在每张卡片下方附上一句启发时，可以用 cards 列表：

Open Library：每本书一个页面

Internet Archive 维护的开放图书目录，可以查版本、借阅电子书。 Oopenlibrary.org

可借鉴： 选书时直接贴书的页面链接，大家看到的是同一个版本。

Project Gutenberg：公版电子书

收录已进入公有领域的电子书，可以免费下载。 Ggutenberg.org+1

可借鉴： 偶尔选一本公版书，没买书的人也能马上加入。

可以这样对 AI 说：

```garden
把 Open Library 和 Project Gutenberg 做成两张资源卡片，附上来源链接和各自可借鉴的地方。
```
