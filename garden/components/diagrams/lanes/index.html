Garden 使用说明/推荐图示

时序图

适合说明谁在什么时候向谁发了什么

适合说明谁在什么时候向谁发了什么。

不是通用建模语言，也不支持任意分支、循环或自动布线。

Typora 和 VS Code / Cursor 共用同一份推荐列表。在 /garden 里，这一项的名称和适用说明与上面相同。选中后会插入下面的 garden compose 说明草稿。补全材料和表达目标，再交给 AI 编译。

推荐说明草稿是起点，不是语法课，也不是唯一合法写法。需要时仍可在同一个 garden compose 里搭配 Markdown 或安全 HTML 基础块。

```garden compose
请根据我提供的材料和表达目标，用 garden compose 做一个「时序图」说明图。

我的材料：
- （粘贴原文条目和需要保留的措辞）

我的表达目标：
- （读者要一眼看出什么）

请你：
- 只根据材料组织内容，不要发明事实或结论
- 自行处理图形语法、布局和手机阅读适配，不要让我学习标签或写 CSS
- 「时序图」是推荐起点：按原文写出参与者和他们之间的消息方向与顺序，不要补出原文没有的分支或循环
- 推荐图示不是唯一合法写法；需要时仍可在同一 compose 里搭配必要的 Markdown / HTML 基础块
- 不要另起一种作者围栏或新语法，只使用 garden compose
```
