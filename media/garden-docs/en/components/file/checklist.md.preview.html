Site Pre-publish Checklist

Before running make update to push changes, verify the following items:

1. Post Front Matter and Paths

  • title, date, and description are filled in, and the filename uses only lowercase letters, digits, and hyphens
  • Local images and attachments live in the post's sidecar folder and use ./<slug>/file.ext relative paths
  • draft: true has been removed from posts ready to publish

2. Local Validation Commands

CommandWhat It Checks
npx garden check content/posts/<slug>.mdChecks a single post's component fields, code diffs, and local asset paths
make checkRuns npx garden sync && npx garden build to validate the full site build
CONTENT_INCLUDE_DRAFTS=1 make devPreviews drafts and scheduled posts locally
